# 실험계획 P002 — dense/tied 300M 기준선 + 격차 축소 매트릭스  [-done(001)]

## 목적
- 동일 실데이터·시드에서 **dense vs tied 손실 격차**(타잉+삼진의 품질 대가)를 측정.
- 메모리 감축(1.82×)을 유지하며 격차를 줄이는 레버들을 각각/조합으로 비교:
  KD+부모초기화 / ternary-LoRA / FiLM / 둘다. 더 긴 학습은 병행 기준선.

## 아키텍처
- `m100` (v5): d=768 ffn=2048 heads=12/3 E=256, prelude2/mid16/coda2, g4, cla2.
- dense 기준선 = 같은 shape에서 `tie_mlp=False, cla=1`.

## 공통 설정
- data ko-en 300M, steps 2289, micro-bs 8, seq 1024, accum 16 (유효배치 131K), lr 1e-3,
  eval-every 100, sched cosine, compile(default), ema 0.999.
- dense 교사·초기화 소스: `runs/ckpt/m100_ko-en_300M_dense.pt`(재사용, 재학습 불필요).
- 격차 = 각 tied val − dense val(3.8241).

## 실행

```cmd
:: dense 기준선(교사·초기화 소스). 한 번만.
python run100m.py train --arch dense --data ko-en --tokens 300M --steps 2289 ^
    --micro-bs 8 --seq 1024 --accum 16 --lr 1e-3 --eval-every 100 --compile --no-ckpt

:: tied 조건 매트릭스 (KD 조건은 --no-ckpt 빼기: 교사가 VRAM에 추가로 올라감)
python run100m.py train --arch tied ... --no-ckpt --ema 0.999 --tag t_base
python run100m.py train --arch tied ... --no-ckpt --ema 0.999 --lora-rank 32 --lora-bits 2 --tag t_lora32
python run100m.py train --arch tied ... --no-ckpt --ema 0.999 --mlp-film --tag t_film
python run100m.py train --arch tied ...           --ema 0.999 --init-from --kd --tag t_kdinit
python run100m.py train --arch tied ...           --ema 0.999 --init-from --kd --lora-rank 32 --lora-bits 2 --mlp-film --tag t_all
```
(`...` = `--data ko-en --tokens 300M --steps 2289 --micro-bs 8 --seq 1024 --accum 16 --lr 1e-3 --eval-every 100 --compile`)

## 판정
- 손실 격차: `≤+0.07` 성립 / `+0.07~+0.15` prelude·coda↑ 또는 g↓ / `>+0.15` |g|max 먼저.
- 각 조건의 (val, 격차, 메모리, |g|max)를 결과 001에 이어 기록.

## 병행 기준선
- 더 긴 학습(예: 600M/4578스텝)으로 undertraining 해소 시 격차 축소 여부 확인.
