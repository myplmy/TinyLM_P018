# 실험계획 P008 (C1) — 점진적 타잉 (untied→tied, LoRA 스케일 어닐)

> **✅ 종결 2026-08-07.** 이 계획의 **원래 목적은 달성됐다 — 단 이 계획의 방법이 아니라 KD 로.**
> 그리고 남은 질문들은 **목적이 서로 달라서** 여기 섞으면 안 된다 → **P043 · P044 로 분리**했다.
>
> ⚠️ **2026-08-07 오전에 이 문서를 "목적 재정의" 로 전면 재작성했다가 되돌렸다.**
> 사용자 지적이 옳다 — **목적이 다른 실험을 한 계획서에 섞으면 판정이 흐려진다.**
> 여기 남은 것은 **원 계획 + 그 목적에 대한 최종 판정**뿐이다.

---

## 원 목적 (2026-07 작성 당시)

KD 없이(또는 KD와 결합) **격차를 줄인다.** 배포 메모리는 그대로(LoRA가 0으로 사라짐).
"제약 점진 부과"(삼진 어닐과 동일 원리): 초반엔 층별 특화(≈untied) → 종료 시 완전 타잉.

## 방법

- 기존 ternary-LoRA를 켜되, **LoRA 출력 스케일 s(t) 를 학습 중 1→0 으로 어닐**(예: 코사인, 60% 지점 0).
- 종료 시 s=0 → LoRA 무효 → **순수 타잉**(1.82× 유지). dense 교사 없이도 격차 축소 기대.

## 선결(구현)

- LoRA forward에 스케일 곱 + 버퍼 스케줄(set_anneal 방식). config `lora_decay` + trainer가 매 스텝 설정.
  → **✅ 2026-08-07 구현 완료**(`--lora-decay`). 구현 자체는 P043 이 승계한다.

## 조건 (m100, ko-en 300M, lr 1e-3, --no-ckpt)

| tag | 옵션 |
|---|---|
| t_prog | --lora-rank 32 --lora-decay (KD 없음) |
| t_prog_kd | 위 + --init-from --kd |

## 비교

- 기존 t_base(+0.1317), t_lora32(+0.0979, 고정 LoRA), t_kdinit(+0.0012)와 대조.
- 목표: (a) **KD 없이** 고정 LoRA보다 격차↓, (b) KD 결합 시 추가 이득 여부.

## 판정

- 격차(vs dense 3.8241), 메모리(LoRA=0이라 1.82×). |g|max 감시(LoRA는 |g| 상승 경향).

## 근거

- Dynamic Layer Tying(2401.12819), share-then-unshare(2110.03848). 삼진 어닐과 동형.
- (추가) RRT — Relaxed Recursive Transformers, [arXiv:2410.20672](https://arxiv.org/abs/2410.20672)

# ★종결 판정 (2026-08-07)

## 1. 원 목적 — **달성됐다. 단 이 계획의 방법이 아니었다**

| 원 목적 | 상태 | 근거 |
|---|---|---|
| **타잉 격차를 줄인다** | ✅ **달성** | **KD + 부모초기화**가 닫았다. 결과 021(paired): `mC` **3.7393 < `p6d` 3.7608** — **타잉 모델이 dense 를 이긴다**. 결과 024 가 wsd 표준에서 재확인 |
| 배포 메모리는 그대로 | 🚫 **구현 상태로는 거짓** | **결과 026**: s=0 이어도 `report()` 가 LoRA 를 계상한다(저장 +11%, 상주 +8.6%) |
| KD 없이 달성 | ⏸ **미검정** | 이 계획은 **한 번도 실행되지 않았다** |

> **★"격차를 줄인다" 는 질문은 이 계획이 아니라 다른 경로로 답이 나왔다.**
> P002·P003·P012 계열의 **KD + 부모초기화**가 +0.132 → **−0.0215** 로 뒤집었다.
> 그러므로 **이 계획을 원 목적으로 계속 열어 둘 이유가 없다.**

## 2. 그럼에도 남은 것 — **목적이 다르므로 분리한다**

| 남은 질문 | **목적** | 이관처 |
|---|---|---|
| 어닐 LoRA 가 **KD 를 대체**할 수 있는가 | **학습 파이프라인 비용**(258분 → 95분) | **[P043](P043_어닐LoRA로-KD대체-파이프라인비용.md)** |
| FiLM 이 현 후보에서 이득인가 | **품질**(거의 공짜 조건화) | **[P044](P044_FiLM-층별조건화-현후보-재검증.md)** |
| 더 공격적 타잉(g16/g32)을 감당하는가 | **메모리** | P043 §후속(근거 생기면 신설) |

**셋은 판정 기준이 서로 다르다** — 비용 / 품질 / 메모리.
한 계획서에 두면 "무엇을 성공이라 부를지" 가 흐려진다.
