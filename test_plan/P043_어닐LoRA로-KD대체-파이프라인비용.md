# P043 — 어닐 LoRA 로 **KD 를 대체**할 수 있는가 (목적: 학습 파이프라인 비용)

> **신설 2026-08-07.** [P008](P008_점진적타잉-LoRA어닐.md) 에서 **목적별로 분리**했다.
> P008 의 목적은 **격차 축소**였고 그건 KD 가 달성했다(결과 021).
> **이 계획의 목적은 다르다 — 같은 품질을 더 싸게 얻는 것이다.**

---

## 1. ★목적 — 품질이 아니라 **비용**이다

**이 계획의 성공은 "더 좋아진다" 가 아니라 "같은데 싸다" 이다.** 판정 기준이 다르다.

| 경로 | 필요한 런 | 벽시계 |
|---|---|---|
| **KD(현 표준)** | ① dense 교사 **117.4분** → ② 학생 KD **141.0분** | **258.4분** |
| plain tied g8 | 학생만 | 89.9분 |
| **이 계획(어닐 LoRA, KD 없음)** | 학생만 (LoRA 연산 추가) | **약 95분(추정)** |

> **품질이 분해능(0.024) 안에서 붙기만 하면 파이프라인이 2.7배 싸진다.**
> 그리고 그 절감은 **여러 조건을 도는 캠페인에 곱해진다** —
> P041 단계2 약 28 GPU시간, P033 18~28시간.

### 1.1 왜 될 법한가

`--lora-decay` 는 LoRA 출력 스케일 `s(t)` 를 **1 → 0** 으로 감쇠시킨다.
초반 s=1 이면 각 층이 자기 LoRA 로 특화(≈untied), 종료 시 s=0 이면 순수 타잉.
**삼진 어닐과 같은 원리** — 제약을 처음부터 걸지 않고 점진적으로 조인다.

구 측정(300M 풀, g4, **KD 없음**): 고정 LoRA r32 가 plain 대비 **−0.0338**.
어닐은 초반 자유도가 더 크므로 **그 이상**을 기대한다.

### 1.2 ⚠️ 왜 안 될 법한가 (같이 적어 둔다)

구 측정(**KD 있음**): `t_all`(KD+LoRA+FiLM) − `t_kdinit`(KD) = **−0.0065 = 분해능 미만**.
**KD 를 켜면 LoRA 이득이 사라진다** → 둘이 **같은 자리를 채우고 있을 가능성**이 높고,
그렇다면 **어닐 LoRA 단독이 KD 만큼 갈 이유가 없다.**

## 2. ★★선결 조건 — **결과 026 이 게이트를 세웠다**

**[결과 026](../test_result/026_20260806_P008-단계0게이트-어닐LoRA는-메모리를-못돌려준다.md)**:
s=0 으로 어닐해도 **`report()` 가 LoRA 를 계상한다** — 저장 **1.0 vs 0.9MB(+11%)**,
상주 **29.1 vs 26.8MB(+8.6%)**.

**즉 "메모리 대가 0" 이라는 전제가 구현 상태로는 거짓이다.**

| 선결 | 내용 | 상태 |
|---|---|---|
| **C1** | **`scripts/export_deploy.py`** — 체크포인트에서 `lora_*` 키를 **제거**하고 `cfg.mlp_lora_rank=0` 으로 저장 | ⏸ **미구현** |
| **C2** | 게이트 재실행 → 저장·상주가 **LoRA 없음과 일치** | C1 후 |
| C3 | `--lora-decay` 배선 | ✅ 완료 |

> **C1·C2 없이 단계1(6 GPU시간)을 돌리면, 존재하지 않는 이득에 붙은 품질 숫자를 얻는다.**
> 결과 026 이 정확히 그것을 막았다.

### 2.1 C1 구현 시 주의

- **로짓 동등성**: s=0 이면 LoRA 기여가 0 이므로 제거 전후 출력이 **같아야 한다**.
  `max|Δlogit| = 0.000e+00` 을 게이트로 쓴다.
  ⚠️ **s 가 마지막 스텝에서 정확히 0 인지 확인**한다 — `lora_decay=0.6` 이면 진행률 0.6 이후 0 이라
  끝에서는 0 이 맞지만, **로그로 직접 찍어 확인**한다(결과 026 §7 한계).
- `state_dict` 키 구조가 바뀌므로 **원본을 덮지 않는다**. `_deploy.pt` 접미사.

## 5. 단계 설계

### 단계 0 — **배포 경로 + 게이트 재실행** ⏸ · GPU 소 · 수 분

C1 구현 → `run_P043_stage0_gate.bat`(결과 026 의 게이트를 export 포함으로 재실행).

**게이트 G0**: 저장·상주가 **LoRA 없음과 일치** + 로짓 `0.000e+00`.
**실패 시 단계1 로 가지 않는다.**

### 단계 1 — **본 실험 3조건** ⏸ G0 통과 후 · GPU **약 4.5h**

`m100R1c`(g8) · **KD 없음 · 부모초기화 없음**(주장이 "KD 없이" 다):

| 태그 | 구성 |
|---|---|
| `p43_base` | plain tied g8 — **대조군** |
| **`p43_anneal`** | `--lora-rank 32 --lora-decay 0.6` — **주 조건** |
| `p43_fixed` | `--lora-rank 32`(어닐 없음) — 어닐 기여 분리(Q3) |

**조건**: 600M 풀 · 300M 학습(2289 steps) · **`--sched wsd --anneal-end 0.80`** ·
lr 1e-3 · seed 1337 · 약 1.5h/런

⚠️ **스케줄을 `mC_wsd`(결과 024)와 정확히 맞춘다** — 안 그러면 단계2 가 무효다.

### 단계 2 — **KD 와의 대결** ⏸ · GPU 0 (체크포인트 재사용) · 수 분

`paired_eval.py` 로 `p43_anneal` vs **`mC_wsd`(3.6442)**.
**SE 0.0005 라 분해능 이하 차이도 본다**(결과 021).

## 8. 한계

- **시드 1개.** 0.024 미만은 `paired_eval` 없이는 못 읽는다.
- **KD 없는 조건만** 본다. "어닐 + KD 조합" 은 **이 계획이 답하지 않는다**(목적이 비용이므로
  KD 를 켜면 절감이 사라진다).
- `--lora-decay` 는 **선형 감쇠 하나**만 구현했다. 형태 스윕은 안 한다 —
  P035 가 삼진 어닐 형태에서 **검출 실패**했으므로(결과 022) 여기서도 둔감할 것으로 본다.
- g8 하나만 본다.
- **벽시계 절감 추정(95분)은 미측정**이다. 단계1 이 실측한다.
