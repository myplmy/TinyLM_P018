# 실험계획 P009 (C2) — 민감도 기반 혼합정밀 삼진

## 목적
전부 삼진이 아니라 **민감한 소수 행렬만 상위 비트(예: int4), 나머지는 삼진**.
메모리 최소 증가로 격차를 줄인다. 우리 `rank_spectrum_v3` 민감도 데이터를 직접 활용.

## 민감도 소스
- 기존 rank_spectrum_v3: 행렬별 저랭크 구조(취약도) — down_proj/up_proj 등이 취약군.
- 보강: 간이 민감도 프로브(레이어/행렬별로 그 부분만 삼진화 시 val 증가량) 1회 측정.

## 선결(구현)
- TLinear에 **per-matrix bits**(2=ternary, 4=int4) 지정 + int4 STE. config로 어느 행렬/층을 상위비트로.

## 조건 (m100, ko-en 300M)
| tag | 상위비트 대상 |
|---|---|
| t_mp_down | down_proj 만 int4, 나머지 ternary |
| t_mp_pc | prelude/coda 전체 int4 |
| t_mp_probe | 프로브 상위 민감 k개 int4 |

## 비교
- t_base(+0.1317)와 격차·메모리. 목표: **소량 메모리 증가로 격차 유의미(>노이즈 0.03) 축소**,
  rank_spectrum의 "excess/비용" 논리와 일관(비용 대비 이득이 큰 행렬만 상위비트).

## 판정
- 격차 감소 ÷ 메모리 증가(효율). KD와 직교라 결합도 가능.

## 리스크

- 근거: HAWQ·LLM-MQ·SHMQ·TWLA(2024~2025) 민감도 기반 MPQ.
