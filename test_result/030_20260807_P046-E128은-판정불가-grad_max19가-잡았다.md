## 2. ★왜 판정 불가인가 — 세 증거가 같은 곳을 가리킨다

| 증거 | 값 | 뜻 |
|---|---|---|
| **`grad_max`** | **19.32** (기준선 0.847) | `CLAUDE.md` 판정 기준의 **"10 이상이면 학습 문제"** 를 넘는다 |
| **step 0 `ce`** | **10.4051** | `ln(32768) = 10.397`. **출력이 완전 무작위** — 같은 밤 `mC_g16` 은 **7.7742** 로 부모초기화 이득이 살아 있었다 |
| **`[init]` 경고 3줄** | 로그 L14~16 | *"임베딩·emb_up 은 **부모초기화하지 않고 난수로 시작**한다"* — **내가 그렇게 구현했고 경고까지 찍었다** |

**즉 이 런은 두 가지를 동시에 바꿨다:**

```
mC_wsd  :  E=256  +  임베딩 부모초기화 O
mC_e128 :  E=128  +  임베딩 부모초기화 X   ← 변수 2개
```

그리고 **헤드가 임베딩과 tie** 돼 있으므로(결과 025) 난수 임베딩은 **입력과 출력을 동시에**
무작위로 만든다. `grad_max` 19.32 는 학습된 몸통이 무작위 머리를 끌어올리며 생긴 값으로 읽힌다.

> **초기 격차가 2.63 nats(10.41 vs 7.77)였고 끝에 0.177 로 줄었다** — **93%가 닫혔지만
> 남은 7%가 초기화 잔재인지 E=128 의 구조적 한계인지 이 런으로는 분리할 수 없다.**

## 4. 조치 — SVD 절단 이식 (구현 완료)

난수 대신 **부모의 실효 임베딩을 최적 저랭크 근사**로 이식한다.

factorized embedding 의 실효 가중치는 두 행렬의 곱이다:

```
W = emb(V × E) @ emb_up(E × dim)          shape (32768, 768), 랭크 ≤ E
```

학생의 `E' < E` 가 표현할 수 있는 **최선**은 `W` 의 랭크 `E'` 최적 근사이고,
Eckart–Young 정리로 그것은 **상위 `E'` 특이값**이다:

```
W ≈ U_k S_k V_k^T   →   emb' = U_k √S_k ,  emb_up' = √S_k V_k^T
```

- `√S` 로 나눠 갖는 것은 두 인자의 스케일을 맞춰 초기 gradient 를 고르게 하려는 것이다
- **`emb` 만 절단하면 안 된다** — 헤드가 tie 돼 있어 출력 쪽이 깨진다. **곱 `W` 를 근사**해야 한다
- 로그에 **보존된 스펙트럼 에너지 %** 와 σ₁/σ_k/σ_E 를 찍는다 → **E=128 이 얼마나 잃는지가
  학습 전에 보인다.** 에너지가 예컨대 99% 면 E=128 은 애초에 값싼 선택이다

★ **검산 완료**(numpy, torch 없이): 재구성이 **최적 랭크-k 근사와 정확히 일치**하고
상대오차가 **Eckart–Young 하한과 소수점까지 같다**(0.405722 = 0.405722).
난수 초기화의 상대오차는 **1.0136**(= 정보 0) — **이 이식이 걷어내는 핸디캡의 크기가 그것이다.**

⚠️ **이 함수가 E=128 을 공짜로 만들지는 않는다.** 로짓 랭크가 `E'` 로 제한되는 **구조적** 한계는
그대로 남는다. 하는 일은 **P046 을 "판정 불가" 에서 "판정 가능" 으로 옮기는 것**뿐이다.
