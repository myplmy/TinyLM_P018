# 실험 004 — P015: 오프라인 KD 캐싱 (top-k) 검증

- 실험계획: P015

## 결과 (tiny 검증)
- kc_online(온라인 KD) 최종 val **8.7950**, kc_offline(오프라인 top32 KD) **10.0775** — **크게 벌어짐**(오프라인 열화).
- kc_offline step0 loss 14.9(|g|6.9)로 초기 폭주 → 초기엔 KD loss 공식 버그(학생 /T 누락·교사 top-k 재정규화)였고 수정함.

## 근본 원인 (수정 후에도 부적합)
- **top-k KD 근사 품질은 교사 분포의 집중도(ppl)에 좌우.** 수식 시뮬레이션:

| 교사 ppl | top32 질량 | top128 | top512 | (klFull≈1.1 기준 오프라인 kl) |
|---|---|---|---|---|
| ~548 | 5% | 12% | 26% | 0.06 / 0.14 / 0.29 (심한 under) |
| ~11 | 44% | 62% | 79% | 0.49 / 0.66 / 0.87 |
| ~4 | 83% | 93% | 98% | 0.74 / 0.80 / 0.91 (양호) |
| ~3 | 95% | 99% | 100% | 0.71 / 0.77 / 0.79 (거의 일치) |

- **우리 m100 교사 val 3.82 = ppl 45** → top-32가 질량 ~20%만 담아 KL 신호 대부분 손실 → under-distill.
  tiny 교사 ppl 11834(near-uniform) → ~1% → garbage. **undertrained(고엔트로피) 교사엔 top-k KD 부적합.**

## 결론·권고
- **오프라인 top-k KD는 현재 부적합**(집중 교사 ppl<~5에만 유효). 코드는 top-k KD로 정확하나 적용 범위가 제한적.
- 정확한 오프라인 대안: **교사의 E=256 병목 중간표현을 캐싱**(logits=emb·intermediate로 전체 재구성) →
  전체 KL 정확. 단 디스크 ~154GB(300M). 큰 비용.
- **권고: 지금은 오프라인 KD 미사용.** KD ~2× 비용은 감수(교사는 매트릭스당 1회성). 1.7B 단계(교사가 더 집중)
  에서 재검토하거나, 필요 시 E=256 중간표현 캐싱으로 정확 구현.
