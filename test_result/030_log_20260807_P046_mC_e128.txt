  2. the paired_eval delta and t value against mC_wsd.
  3. grad_max from the json.
  4. the report() block - the ternary/embedding parameter counts.
  5. the header conditions. If any differ from mC_wsd the delta is INVALID.

HOW TO READ IT
  delta under +0.024
      -> ACCEPT for review. residency -18.8 percent for free.
  +0.024 to +0.08
      -> a real tradeoff. Worth it only if the deployment target is memory
         constrained (see 08_paper_review section 3, the ESP32 table).
  above +0.08
      -> reject at E=128. Try E=192 (-9.4 percent residency) or close the axis.
  ***ALSO CHECK*** the [emb] and [init] warning lines. If the [init] warning is
  absent, the shape guard did not fire and something is wrong.
