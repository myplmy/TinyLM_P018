## 4. 판정 — **채택. 그리고 축 종결**

| 게이트 | 기준 | 결과 |
|---|---|---|
| **G-a** 오버라이드 | `[micro_group]` 줄 + packed 12.5MB대 | ✅ |

| **G2** 회계 | packed −3.6 ± 0.2% | ✅ **−3.62%** |
| **G3** 안정성 | `grad_max` < 3 | ✅ 1.621 |

### 4.1 축이 닫히는 이유

`dim = 768` 이고 `768 % 512 ≠ 0` 이므로 `TMTConfig.__post_init__` 의
`dim % micro_group == 0` 이 **g512 를 구조적으로 막는다**. `ffn_dim = 2048` 은 통과하지만
어텐션 q/o/k/v 의 `in_f = 768` 이 안 된다.

> **g256 이 상한이고 그 상한에서 대가가 0 이다.** P045 가 `n_middle = 16` 때문에 g16 에서
> 타잉 축을 닫은 것과 **같은 형태**다. **런 하나로 축 하나가 닫혔다.**

### 4.2 ★다른 레버와의 관계 — **직교이고 곱해진다**

| 레버 | 무엇을 줄이나 | packed | fp32 상주 |
|---|---|---:|---:|
| g16 타잉(P045) | 유니크 삼진 **개수** | −7.4% | −8.0% |
| prelude/coda 1+1(P048) | 유니크 삼진 **개수** | −19.0% | −20.4% |
| **`micro_group` 256(P051)** | **파라미터당 비트** | **−3.62%** | **0** |

★**용량을 안 덜어내므로 결과 032 §8.3 의 볼록성 바깥**이다 —
`m100R1q`(g16+p1c1, packed 9.612MB) 위에 얹으면 **약 9.26MB** 로 계산된다.
⚠️ **계산값이다.** 실측하려면 단계2 가 필요하고, 그건 **P050 결과를 보고** 정한다.

⚠️⚠️ **인용 규약**: 이건 **packed 전용 레버**다. `fp32 상주`·`int8 상주`는 **하나도 안 준다**
(상주식에 bpw 가 없다 — 함정 1). **"메모리 −3.6%" 라고 쓰면 틀린다. "저장 −3.6%" 라고 쓴다.**
