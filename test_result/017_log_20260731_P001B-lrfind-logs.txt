HOW TO READ IT
  grid  : the largest lr with grad_max under 10 AND loss decreasing. This is the
          number to act on. Compare its suggested_lr against 1e-3.
  range : diverge_lr is a useful CEILING. Ignore its suggested_lr - safety=3.0
          already proved too conservative once (P001: suggested 5.6e-4, reality 1e-3).

DECISION RULE
  grid picks 1e-3            -> current LR confirmed. Close this out, P033 unblocked.
  grid picks ABOVE 1e-3      -> headroom exists, but DO NOT adopt it from 60 steps.
                                Short runs read speed only, never quality (CLAUDE.md).
                                Adopt only after one full 300M run beats p6d 3.7045
                                by more than 0.024. That run is the real evidence.
  grid picks BELOW 1e-3      -> we have been training slightly too hot the whole time.
                                Check grad_max in past json before believing it.
  accum 8 and 16 differ      -> batch-dependence confirmed. Then P033's larger batch
                                needs its OWN lrfind, not this number.

LIMITS: no mlp-group / no sparse34 (plain arch only) / full FP, no ternary anneal /
  safety=3.0 not adjustable from the CLI / this does not measure quality at all.
