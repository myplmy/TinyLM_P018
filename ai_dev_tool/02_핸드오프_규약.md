# 02 — 핸드오프 메모 규약 (장기기억)

> **목적**: 세션이 끊겨도 **작업 기록이 유실되지 않게** 한다.
> 새 세션이 `handoff/` 의 최신 메모 **하나만 읽고** 이어받을 수 있어야 한다.

## 1. 언제 쓰나

| 시점 | 무엇 |
|---|---|
| **세션 컨텍스트 70% 전후** | 중간 핸드오프(유실 방지). 프로젝트 지침에 명시된 규칙 |
| **작업 단위가 끝날 때마다** | 사용자 지시 1건이 끝나면 그 자리에서 갱신 |
| **세션 종료 시** | 최종 핸드오프. 다음 세션 시작 프롬프트까지 포함 |

## 2. 파일 규약

- 경로: `handoff/{YYYYMMDDHHMM}_HANDOFF.md`
- 첫 줄: `# HANDOFF {날짜 시각} — {이 세션이 남긴 것 한 줄}`
- 둘째 줄: 이전 핸드오프 링크
- **요약하지 않는다.** 신규 세션이 이것만 읽고 이어받을 수 있게 쓴다.
- `CLAUDE.md` 의 "현재 상태" 줄에서 **최신 핸드오프를 가리키게** 갱신한다.

## 3. ★고정 섹션 (이 순서로)

```markdown
# HANDOFF {시각} — {한 줄}

이전: [{이전파일}]({이전파일}).
**코드가 정본**(`tinylm/`). 영구 규범은 `CLAUDE.md`. 장기기억은 `ai_dev_tool/`.
**★AI 는 학습/GPU 코드를 직접 실행하지 않는다** — 배치·스크립트만 만들고 **실행은 사용자**.

> **이 문서는 요약하지 않는다.**

## 0. 사용자 지시사항과 그 목적

| # | 사용자가 지시한 것 | **AI 가 판단한 목적** | **그래서 필요했던 작업** | **실제로 한 것** | 결과 |
|---|---|---|---|---|---|

★"지시한 것" 과 "목적" 을 따로 적는다. 목적을 잘못 읽으면 지시를 다 지켜도 헛일이 된다.
★"필요했던 작업" 과 "실제로 한 것" 이 다르면 **그 차이를 반드시 남긴다** — 다음 세션이
  그 자리에서 이어야 할 지점이다.

## 1. ★가장 중요한 것 세 가지 (먼저 읽을 것)

## 2. ~ N. 항목별 상세 (근거·수치·판정)

## N+1. 사용자에게 부탁하는 것
(실행할 배치 / 확인할 판단 / git 명령 — **AI 가 못 하는 것만**)

## N+2. 다음에 하면 좋을 것 (권장 순서)
| 순 | 실험 | 배치 | GPU | 예상 시간 | 권장 근거 |

## N+3. 커밋 메시지 제안 (한국어 제목 + 본문)

## N+4. 신규 세션 시작 프롬프트 (제안)

## N+5. 참조 치트시트
```

## 4. ★반드시 들어가야 하는 것

- [ ] **사용자 지시사항 원문**과 **AI 가 이해한 목적**을 **분리**해서
- [ ] **하려던 것 vs 실제로 한 것**의 차이(있으면)
- [ ] **판정이 뒤집힌 것**과 그 이유 — 조용히 덮어쓰지 않는다
- [ ] **아직 답이 없는 질문**(가장 자주 유실되는 항목)
- [ ] **사용자 대기 항목**(실행·승인·git) — AI 가 못 하는 것만
- [ ] **다음 권장 실험**: 실험번호 · 단계 · **배치 파일명** · **예상 시간** · **권장 근거**
- [ ] **커밋 메시지**(한국어 제목 + 본문)
- [ ] **신규 세션 시작 프롬프트**

## 5. 쓰지 말아야 하는 것

- **"~할 예정"** 만 적고 실제 상태를 안 적는 것. 상태는 ✅/⏸/🚫 로 명시한다
- **결론만 적고 근거 수치를 뺀 것.** 다음 세션이 재검증할 수 없다
- **"조치 완료" 를 파일 diff 없이 적는 것**(결과 014 초판 사고)
- 이전 핸드오프의 **요약본**. 링크를 걸고 **새 내용만** 쓴다

## 6. 3층 기억 구조 (이 저장소의 규약)

| 층 | 위치 | 무엇 | 수명 |
|---|---|---|---|
| **영구 규범** | `CLAUDE.md` | **매 프롬프트 반드시 확인해야 하는 것만.** 컴팩트 유지 | 프로젝트 전체 |
| **장기기억** | `ai_dev_tool/*.md` | 함정 원장 · 규약 · 절차. **펼쳐 볼 때 읽는다** | 프로젝트 전체 |
| **단기기억** | `handoff/*.md` | 세션 컨텍스트. 다음 세션이 이어받는 유일한 통로 | 세션 |

> **판단 기준**: "이걸 몰라서 **매 프롬프트** 사고가 나는가?" → `CLAUDE.md`.
> "필요할 때 찾아보면 되는가?" → `ai_dev_tool/`.
> "이번 세션에서만 유효한가?" → `handoff/`.
