| 층 | 위치 | 무엇 | 판단 기준 |

## 여기 두지 않는 것

- **실험 결과** → `test_result/` (결과가 정본이다)
- **실험 계획** → `test_plan/`
- **방법론 원장**(기법별 상태·트레이드오프) → `docs/methods/`
- **실험 조건 기준표** → `docs/EXPERIMENT_BASELINES.md`
- **누적 판정·모델안** → `docs/review/`

## 갱신 규칙

- **항목을 지우지 않는다.** 철회는 취소선 + 사유로 남긴다 — 왜 철회됐는지가 정보다.
- `CLAUDE.md` 가 길어지면 **여기로 내린다.** 반대로, 같은 사고가 **반복**되면 `CLAUDE.md` 로 올린다.
- 파일이 6개를 넘으면 색인을 다시 짠다(찾을 수 없는 기억은 없는 기억이다).
