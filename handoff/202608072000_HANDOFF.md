## 4. (3) ★P037 단계4 오류 — 원인·수정·재발 방지

### 4.1 무슨 일이

```
TypeError: prepare() got an unexpected keyword argument 'lora_decay'
```

`--lora-decay` 를 `train()` 에 넘기려고 `cli.py` 를 **문자열 치환**으로 고쳤는데,
쓴 패턴 `doc_min_chars=a.doc_min_chars)` 이 **`prepare()` 호출부에도 있었다.**
`replace(..., 1)` 이 **첫 번째(prepare)** 를 바꿨다.

**이 배치는 그 뒤 처음 돌아서 대신 죽었을 뿐이다. P037 단계4 자체는 아무 문제가 없다.**

### 4.2 ★기존 그물 4개가 전부 통과시켰다

| 검사 | 왜 못 잡았나 |
|---|---|
| `py_compile` | **문법은 정상** |
| `check_attrs.py` | `cfg.X` 오타만 본다 |
| `check_batch_flags.py` | `--lora-decay` 는 **파서에 있다**(이름만 보는 도구) |
| 스모크 | **`train` 만** 돈다. 깨진 것은 **`prepare`** |

### 4.3 조치

1. **수정**: `lora_decay` 를 `prepare()` 에서 빼고 `train()` 에 붙였다
2. **`scripts/check_call_kwargs.py` 신설** — AST 로 `cli.py` 의 호출 키워드를 **대상 함수
   시그니처와 대조**. torch 불필요. **회귀 검증 완료**(일부러 되돌리니 `cli.py:167` 을 정확히 지목)
3. **`run_P037_stage4_exhaust.bat` 에 가드 추가** — 실행 전 이 검사를 돌리고 실패 시 정지
4. `CLAUDE.md` 함정 20 · `ai_dev_tool/01` 에 기록
