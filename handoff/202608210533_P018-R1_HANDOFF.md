## 2. AI가 이해한 연구 목적

주 질문은 학습 후 압축이 아니다. Dense Teacher와 MLP-only g6 Tied Teacher를 같은 MobileLLM-125M base, 공식 tokenizer, 같은 exact cache/budget/schedule에서 각각 random initialization부터 독립 학습해 다음을 추정하는 것이다.

- teacher quality 차이.
- logical/unique parameter와 실제 KD teacher memory 차이.
- 동일 student가 Dense/Tied teacher로 KD될 때 student quality 차이.

Optional Dense-to-Tied 압축은 이 주 비교가 끝난 뒤 별도 arm이다. 고정 margin이 없으므로 “동등/동일/품질 보존”을 결론으로 선언하지 않고 raw difference와 uncertainty를 보고한다.

## 3. 확정된 주 architecture

### Dense Teacher

- MobileLLM-125M: 576d, FFN 1536, 30 layers, 9 Q heads, 3 KV heads, vocab 32000.
- 30개 독립 attention, 30개 독립 MLP.
- input/output embedding은 같은 Parameter 공유.
- unique parameter 124,635,456.

### Tied Teacher

- Dense와 동일한 base architecture.
- MLP-only tied g6.
- 그룹: L0-5, L6-11, L12-17, L18-23, L24-29.
- attention 30개는 계속 독립.
- logical parameter use 124,635,456.
- static unique parameter 58,280,256, dense 대비 -66,355,200 (-53.24%).

`g8`은 8+8+8+6이 되어 비대칭이므로 주 조건에서 제외했다. g10/g15는 후속 sharing-strength 실험 후보일 뿐이다.
