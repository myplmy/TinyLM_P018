## 1. ★가장 중요한 것 세 가지

1. **★★U2 는 부정이고, 우회할 수 없다.**
   `quantize_i2_s` 가 **텐서 전체에서 max 하나**를 뽑아 `scale_ptr[0]` 에 넣는다. TL 도
   `aligned_malloc(sizeof(bitnet_float_type))` — **1개**. 우리는 `micro_group=128` 로
   **약 428,000개**다. 그리고 우리 α 는 shape 이 **`(O, I//g)`** 라 **활성값에도 출력에도 못 접는다.**
   → **텐서당 α 로 재양자화 = 가중치가 바뀐다 = 로짓 동등성 원리적으로 불가.**
   **P014B 의 게이트 G1 을 "동등성" 에서 "공통 원문 bpb 허용 오차" 로 개정했다.**
2. **★그런데 지름길이 생겼다 — 더미 벤치.**
   `utils/generate-dummy-bitnet-model.py --model-size 125M` 로 **임의 크기 모델을 벤치**할 수 있다.
   **변환기도, 우리 체크포인트도, 품질 논의도 없이 U1("우리 크기에서 이득인가")을 먼저 답한다.**
   **이득이 없으면 거기서 P014 가 끝난다.** → **P014B 단계0.5 신설, 단계1·2 를 뒤로 밀었다.**
3. **★U5 빌드 실패의 원인은 사용자 환경이 아니다.**
   configure 는 성공했고 **링크에서만** 죽었다(`undefined symbol: quantize_i2_s`).

   그리고 `src/CMakeLists.txt` 에 **`set()` 이 두 번 연속**이라 앞의 파일이 **덮어써진다.**

## 2. (1) ★단계0 결과 — 코드로 확정한 것

전문: `docs/20260807_T-MAC와-bitnetcpp-실사-우리구조적용가능성분석.md` **§13**

### 2.1 U2 — 스케일 단위 🚫

```c
// src/ggml-bitnet-mad.cpp:51  quantize_i2_s
int n = nrow * n_per_row;                   // 텐서 전체
for (int i = 0; i < n; ++i) max = fmax(max, fabs(src[i]));
double i2_scale = max;
...
scale_ptr[0] = i2_scale;                    // ★스케일 딱 하나
```

```c
// include/bitnet-lut-kernels.h  ggml_bitnet_transform_tensor
scales = (bitnet_float_type *) aligned_malloc(sizeof(bitnet_float_type));  // ★1개분
scales[0] = (bitnet_float_type) i2_scales[0];
```

| | 스케일 개수 |
|---|---|
| I2_S · TL1 · TL2 | **텐서당 1개** |
| 우리 `mC` | `54.85M / 128` ≈ **428,000개** |

**우회 불가 이유**: `_alpha` shape 이 `(O, I//g)` — **출력 행에도 입력 그룹에도** 의존한다.
활성값 pre-scale 도, 출력 post-scale 도 성립하지 않는다.

### 2.2 U3 — 활성값 ✅ (좋은 소식)

```c
// src/ggml-bitnet-lut.cpp:51  ggml_bitnet_can_mul_mat
src1->type == GGML_TYPE_F32 &&      // ★활성값 F32
dst->type  == GGML_TYPE_F32) {
    if (src1->ne[1] <= 1) return true;   // ★배치 1 전용
```

| 경로 | 활성값 |
|---|---|
| **TL1/TL2** | **F32** ✅ 양자화 불필요 |
| I2_S | **int8**(W2A8) — `ggml_vec_dot_i2_i8_s` |

★ **`ne[1] <= 1` = 배치 1 디코드 전용**이고 **우리 벤치가 정확히 그것**이다. 우연히 딱 맞는다.
⚠️ 반대로 **prefill 에는 LUT 가 안 걸린다** → **TTFT 는 안 빨라진다.**

### 2.3 U1 — 길이 갈렸다 ⚠️

`include/kernel_config.ini` 전문:

```ini
[Kernels_0] m=3200 k=8640   [Kernels_1] m=3200 k=3200   [Kernels_2] m=8640 k=3200
```

`transform_tensor` 가 **그 값들로 분기**한다. **BitNet-3B shape 이고 우리(768/2048)는 없다.**

| | shape 의존 |
|---|---|
| **TL1/TL2** | 🚫 **하드코딩. codegen 필요** |
| **I2_S** | ✅ **무관** — `gemm-config.h`(ROW_BLOCK 4 / COL_BLOCK 128 / PARALLEL 4)의 일반 블록 GEMM |

→ **단계0.5·단계2 는 I2_S 로 먼저 한다.**


| 가설 | 내용 |

**H1 정황**: 로그의 `ggml version: 0.15.3` / `commit 390c30775` 는 **꽤 최신**이고,
