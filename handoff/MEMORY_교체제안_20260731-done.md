## 붙여넣을 본문 (여기부터)

**Purpose & context**

Uboy 는 PyTorch 로 CPU·엣지 배포용 초경량 LLM 아키텍처(**TinyLM**)를 처음부터 학습시켜 만들고 있다.
1순위 목표는 **연산이 아니라 배포 메모리**다. 사전학습 모델 변환이 아니라 **from-scratch 학습**이다.
작업은 Windows + RTX 4070 Ti Super(16GB) 단일 GPU.

**작업 규약 (반드시 지킬 것)**

- **AI 는 사용자 환경에서 학습/GPU 코드를 직접 실행하지 않는다.** 코드 수정만 하고,
  실행이 필요하면 **명령어와 순서를 제시해 대리 실행을 요청**한다. 사용자가 로그를 회신한다.
- **git 과 파일 삭제는 사용자가 Windows 셸에서** 수행한다.
- **계획 작성·구현은 보고 후 승인받고 진행**한다.
- **`.bat` 는 순수 ASCII** — 한글·`%`·`chcp`·escape 안 된 `<>|` 금지.
- 서술은 **한글**, 변수·파일명은 **영문**.

**현재 상태 (2026-07-31)**

- 코드 v6(`tinylm/` 패키지), 아키텍처 v5(QK-norm 등 안정화 완료). 학습은 안정적이다.
- 표준 실험: `m100` preset(132.5M) / `ko-en` / **300M 토큰** =
  `--steps 2289 --micro-bs 8 --accum 16 --seq 1024`(유효배치 131K) / 풀 **600M** / `lr 1e-3` /
  **`--sched wsd`**(2026-07-31 개정) / `--compile` / dense 는 `--no-ckpt`.
- **σ(재현 노이즈) = 0.012, 실무 분해능 0.024.** 이보다 작은 차이로 서열을 매기지 않는다.
- 후보 모델: `mA_g4s34_k4`(g4+3:4희소+KD k4) / `mC_g8_k4`(g8+KD k4) / `p6d`(dense 기준선).
  품질은 셋이 서로 노이즈 안. **REVIEW1 승자는 보류 상태**(아래).

**핵심 학습 — 계측 (이 프로젝트에서 반복해서 대가를 치른 것)**

- **★"내가 재려던 양을 정말 재고 있는가"를 항상 먼저 의심한다.** 실제 사고 4건:
  ① CPU "추론 속도" → 실제로는 매 forward 재양자화 비용
  ② KV 캐시 "정확성 게이트" → 실제로는 bf16 near-tie 빈도 (캐시는 정상이었다)
  ③ "저장 메모리" → 배포 상주량과 31~45배 차이
  ④ val 문서 통계 → eos 를 빈도로 추측해 경계를 절반만 찾음
- **예상 밖으로 깨끗한 패턴**(FLOPs 가 같은데 2배 빠름 등)이 보이면 **아키텍처가 아니라 계측**을
  먼저 의심한다.
- **런 비교는 `final`(100 iters) 끼리만.** `best` 는 50-iter eval 의 최소값이라 하향 편향이고,
  실제로 판정 부호가 뒤집힌 적이 있다.
- 속도는 **정상상태 ms/step** 으로 환산하고(`(누적평균×N − step0)/(N−1)`),
  **단독 GPU 점유일 때만** 비교한다(동시 실행 시 14% 오염 관측).
- 안정성은 인쇄된 `|g|`(10스텝 샘플)가 아니라 json `grad_max` 로 본다.

**핵심 학습 — 메모리 (프로젝트 1순위 목표)**

- **저장(packed) ≠ 상주(runtime).** 인용할 때 **어느 쪽인지 반드시 명시**한다.
  상주 = `유니크 삼진 파라미터 × 4B × 2벌(latent+dequant) + 33MB` — **bpw 가 식에 없다.**
- **타잉(g↑)은 저장과 상주를 둘 다 줄이고, 삼진·희소(bpw↓)는 저장만 줄인다.**
  그래서 **순위가 역전한다**: 저장은 mA<mC 인데 **상주는 mC<mA**.
- **bpw 를 인용할 땐 규약을 명시한다** — `코드만` / `코드+스케일` / `+컨테이너`.
  **서로 다른 규약의 두 값으로 비율을 만들지 않는다**(이 실수로 2.64× 가 실제 2.11× 였다).

**핵심 학습 — 데이터**

- **데이터 풀 ≥ 학습토큰 × 2.** 같은 300M 학습에서 풀만 2배로 늘려 dense 가 −0.12 개선됐다.
  **학습시간 증가 0 의 무료 레버.** 풀이 다른 런끼리는 비교 금지.
- 교차 데이터셋 bpb 비교는 **토크나이저·val 셋이 다르면 무효**.
- `ko-en` val 은 건강하다. `ko-edu-en` 은 거대 문서 7개가 손실의 53% → 폐기·재생성 대상.

**핵심 학습 — 논문 인용**

- **초록만 읽고 인용하지 않는다.** Sherry(3:4 희소) 논문을 초록 수준으로 읽어 **3건을 오독**했고,
  그중 하나("Arenas 는 우리 어닐과 같다")는 **논문이 필수라고 한 부품을 빼고 실험**하게 만들었다.
- 인용 전 확인할 것: **비교 기준선 숫자**(무엇 대비 몇 %인가) · **필수 부품 목록** · **측정 조건**.

   지금 정하면 미구현 기능에 베팅하는 것이다.

**Approach & patterns**

- 값싼 진단 → 비싼 학습 순서. 각 단계가 다음 단계의 게이트.
- 실험 전 `exp-preflight`(조건 정합성) + `exp-plan`(문서 양식) 둘 다 적용.
- 계획서에 **예측 절**과 **한계 절**을 반드시 쓰고, 결과가 나오면 **예측 대조**를 명시적으로 한다.
- 가설 기각도 결과다. 음성 결과로 실험 라인을 **종결**하는 것을 성과로 친다.
