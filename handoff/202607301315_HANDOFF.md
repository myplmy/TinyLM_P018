## 4. 사용자 성향 / 세션 운영 스타일 (이번 세션 강화된 것만)

- **"권장근거와 함께 보고"** 를 반복 요구. 결론만이 아니라 **왜 그 순서인지·비용 대비 정보량**을
  명시해야 한다. 근거 없는 우선순위 제시는 되돌려받는다.
- **한계·불확실성을 명시하라**는 요구가 강하다. `exp-preflight` 스킬 지시 때 "실험설계 검증이므로
  실제로 그러한지는 테스트해봐야 안다는 한계를 명확히" 라고 직접 지시함 → 도구·문서에 **보증하지
  못하는 것**을 별도 절로 쓰는 것이 이 프로젝트 규범이 됐다.
- **결론 정정 수위를 직접 정한다.** 005 vs 006 충돌 때 "병기만, 정정은 확인런 후" 를 선택했다.
  → AI 가 임의로 기존 결론을 덮어쓰지 말고 **선택지를 제시**할 것.
- **파일 재활용 시 이름 분리**를 명시 요구(P007B/P021B). 기존 실험 기록을 덮지 않는 것을 중시한다.
- 완료된 산출물은 **적극적으로 정리·삭제**한다(bat 3개 삭제). 삭제 전 **이력 보존 확인**을 요구한다.
- 커밋 메시지는 **한국어 제목+본문** 으로 제안받기를 원한다. 커밋은 직접 수행.

## 5. 이번 세션에서 학습·기억한 사항

### ★새로 확정된 사실 (수치 정본은 `runs/logs/*.json`, 표는 기준표 §2)

| 사실 | 수치 | 근거 |
|---|---|---|
| 타잉 격차는 토큰으로 닫히지 않는다 | +0.149/+0.168/+0.166 (100/300/600M) | 006 |
| KD 이득은 예산↑에서 감소 | -0.110 → +0.062 → +0.098 | 006 |
| **KD 가 dense 를 능가하는 건 dense 가 약할 때만** | 3사례 일관(005·006·009) | — |
| **데이터 풀 2× = -0.12** (학습시간 0) | 3.8241 → 3.7045 | 006 |
| 3:4 희소 단독 비용 | +0.035(g4) / +0.056(g8), 메모리 1.45× | 008 |
| 희소와 타잉은 **초선형 경합** | g8 비용이 g4 의 1.6배 | 008 |
| `--no-ckpt` | -17.3%, 13.5GB | 007 |
| micro_bs↑ 이득 0 | 토큰당 -0.9% (단 15.2GB=스필 교락 → ② 로 확정) | 007 |
| FP8 순수 GEMM | **1.63~2.08×** (Ada 2:1 비율 일치) | 010 |
| **GEMM 은 스텝의 약 50%** | 97.5 TFLOP/step ÷ 80 TFLOPS = 1.22s vs 2.467s | 010 |
| → GEMM 전용 최적화 상한 | 2× 해도 스텝 **-23%** | 010 |

### ★함정 (이번 세션에 새로 판명된 것)

1. **`grad_max` vs 인쇄 `|g|`** — 인쇄값은 10스텝 샘플이라 스파이크를 숨긴다.
   `sp_base` 인쇄 최대 4.51 vs 실제 `grad_max` **10.79**. 안정성 판정은 **반드시 json**.
2. **250스텝 런은 불안정 구간이다** — `grad_max` 10.8/35.4(우리 "10 초과=문제" 선 초과).
   그래서 결과 007 의 0.11 nats 발산은 **σ 의 추정치도 상한도 아니다.** σ 는 여전히 미측정.
   (이건 제가 이전 턴에 잘못 진단했다가 검증 단계에서 정정한 것 — 같은 실수 반복 금지.)
3. **Loader 는 torch RNG 와 별도 np rng** 를 쓴다(1234/99 하드코딩). 시드를 다룰 때 반드시 확인.
   **val 시드는 절대 고정** — 흔들면 서로 다른 crop 에서 val 을 재게 되어 비교가 깨진다.
4. **`compare` 는 구 로그에서 여전히 근사값**이다. `deploy_mb` 는 이번 세션 이후 런에만 있다.
5. **풀÷학습토큰 비율**을 봐야 한다. 풀 크기가 같아도 학습토큰이 늘면 비율이 준다.
   결과 006 의 600M 행이 비율 1× = 결핍(단 교락 방향이 결론에 유리해 뒤집히진 않음).
6. **P026 초판이 `--pool-tokens` 를 빠뜨렸다**(이번 세션 수정). 새 배치 작성 시 기준표 §1 대조 필수.

### 세션 도구 팁

- `.claude/` 는 파일툴 차단 → **셸 heredoc** 으로 작성(스킬 3종 그렇게 만듦).
- 마운트에서 `mv` 는 되고 `rm`(unlink) 은 차단. `git` 쓰기도 차단(`index.lock` 권한 오류).

  1회 눈으로 확인 필요.
- 결과문서 수치는 **로그 인쇄값이 아니라 json 과 대조**해야 한다(`log-to-result` 스킬에 절차화).
