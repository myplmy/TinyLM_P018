### ★발견 1 — g16 과 prelude/coda 가 **같은 효율선** 위에 있다

packed·fp32상주·유니크삼진 **세 지표 전부 1.19~1.20배** 차이.
→ **국소 법칙 가설: 약 0.0035~0.0041 nats per 유니크 삼진 100만 파라미터.**

⚠️ **국소 선형화이고 법칙이 아니다.** `mC`(54.85M) vs `p6d`(123.86M)에 적용하면 **+0.255** 여야
하는데 실제로는 **`mC` 가 이긴다**(−0.0254, 결과 011 §1) — KD·부모초기화가 그 구간을 메운다.
**적용 범위 = 4.7~12.1M · KD+부모초기화 파이프라인 안 · 같은 학습 예산.**
**P048 단계2 가 이 선형화를 직접 검정한다**(예측 +0.062).

### ★발견 2 — ⚠️ **이 문서의 §A.3 우선순위가 틀렸다**

§A.3 은 *"A-6(prelude/coda) > A-4 > A-1 > A-5"* 로 놓고 **A-6 의 상주 이득을 ⚙−14%** 로 적었다.
그 숫자는 **int8 경로** 것이었다. 실측:

| | 이 문서가 적은 값 | 실측 |
|---|---|---|
| A-6 상주 | ⚙−14% | **fp32 −20.4% / int8 −13.7%** (둘 다 맞다. **경로가 다르다**) |
| A-6 packed | ⚙13.12 → 11.4MB | **13.050 → 10.574MB** (더 좋다) |
| **E=128 상주** | ⚙**−18.8%** ← 이 값으로 야간큐 순서를 정했다 | **fp32 −3.6% / int8 −18.8%** |

> **★★함정 1(저장 vs 상주)의 3번째 얼굴: "상주" 안에서 fp32 상주와 int8 상주가 갈린다.**
> E=128 은 **int8 경로에서만** 1위다(임베딩이 fp32 로 남으므로 삼진이 int8 로 줄면 비중이 커진다).
> 그런데 결과 016 §10 은 *"int8 은 RAM 부족 시 마지막 수단이지 기본 배포 경로가 아니다"* 라고
> 적어 두었다. **확정하지 않은 경로의 숫자로 순서를 정한 것이 오류다.**
> → **이후 모든 레버 인용에 "어느 배포 경로" 를 병기한다.**

### ★발견 3 — 판정을 살린 것은 새 도구가 아니라 이미 있던 규칙

`mC_e128` 의 Δ 는 +0.1768 로 "기각" 이 될 참이었다. `CLAUDE.md` 가 이미 적어 둔
*"`> +0.15` 는 `|g|max` 먼저 확인(10 이상이면 학습 문제)"* 가 발화해 **`grad_max 19.32`** 를
드러냈고, **판정이 "기각" → "판정 불가" 로 바뀌었다.**
**인쇄 `|g|` 는 0.43 으로 그날 셋 중 가장 안전해 보였다**(함정 4).

## E.1 ★2차 리뷰(REVIEW2) 시기 판단

**지금은 아니다.** 이유:

| 조건 | 상태 |
|---|---|
| 야간 큐 3건(P014C-0 · P046 · P045) | ⏳ **실행 대기** — 셋 다 **메모리·커널 축의 핵심 분기** |
| P040(타잉 학습속도) | ⏸ 미실행 |
| **`ko-en` 스팸률**(D-1) | ⏸ **미측정** — 이게 **모든 기준선을 흔들 수 있다** |
| P014C 단계0 | ⏳ **커널을 만들지 말지가 여기서 갈린다** |

> **★REVIEW2 는 "야간 큐 3건 + P040 + D-1 측정" 이 끝난 뒤가 적기다.**
> 그때는 ①메모리 로드맵의 다음 단계가 확정되고(P014C 분기) ②남은 아키텍처 노브가
> 전부 측정되고(g16·E=128 로 타잉·임베딩 축 종결) ③데이터 오염 여부가 판명된다.
>
> **예상 시점: 위 5건 완료 직후.** GPU 로는 약 **8h(야간 큐) + 40분(P040)**, D-1 은 GPU 0.
> **그 전에 리뷰를 쓰면 세 축이 다 미결인 채로 판정하게 된다.**

### ⚠️ 다만 **먼저 써야 할 문서가 하나 있다**

**D-1 이 양성이면 REVIEW1 의 모든 수치가 −0.3 나쁜 기준선 위에 있다는 뜻**이다.
그건 리뷰를 다시 쓰는 문제가 아니라 **기준선을 다시 만드는 문제**다.
→ **D-1 측정을 REVIEW2 보다 먼저, 그리고 야간 큐와 병행해서** 한다.
