# 1. 아키텍처 구조

블록 구성·타잉·조건화 등 모델 구조 자체의 설계·개선.

| 기법 | 상태 | 버전 | 작동원리(개선 기여) | 트레이드오프 | 특기 |
|---|---|---|---|---|---|
| **prelude/coda 분리** (2+2 완전 독립) | ✅ | v4~ | 첫·마지막 층은 임베딩 입력/lm_head 출력 조정이라 질적으로 다름. 공유 풀에 넣으면 중간층 자유도로 회복 불가. 2+2 독립이 단일 최대 이득 | 독립층만큼 메모리 약간↑ | 근거: Tying the Loop(EPFL). 전층 타잉 대비 격차 0.097~0.202로 최대 |
| **어텐션 층별 독립** | ✅ | v4~ | 타이드 레이어를 구별시키는 건 라우터가 아니라 어텐션. Q/O·(소유)K/V를 층마다 둠 | MLP 대비 파라미터 작아 유지비 저렴 | ablation: 어텐션 풀면 손실 0.03~0.058 개선 |
| **MLP만 g층 타잉** (`mlp_group=4`) | ✅ | v4~ | 파라미터 75%인 MLP를 4층씩 1그룹으로 공유 → 메모리 대폭↓ | 손실 격차(+0.05~0.07 예상, 실측 +0.118@300M undertrained) | g=2/6/8 스윕 가능. 큰 모델일수록 타잉 손해↓ |
| **CLA2** (인접 2층 K/V 공유) | ✅ | v4~ | K/V를 그룹 첫 층만 계산·저장, 나머지 재사용 → KV 캐시·메모리 절반 | 표현력 소폭 | 가중치 타잉과 무관한 별도 축. Q/O는 층별 독립 유지 |
| **Factorized embedding** (V×E+E×d, E=256) | ✅ | v4~ | 임베딩을 저랭크 분해 → 임베딩이 더는 메모리 바닥이 아님. lm_head도 전치 공유로 저렴 | 로짓 랭크가 E로 제한 | 임베딩 메모리 최대 9배↓(64k+E=512 조합 시) |
| **adaLN** (층별 scale/shift/gate) | ✅ | v4~ | 공유 MLP라도 층별 정규화 게인으로 입력을 다르게 변조 → 층 차별화 | 거의 공짜(파라미터 미미) | mode-delta와 동등 효과 확인(0.0134 vs 0.0132) |
| **QK-norm** (q·k 내적 전 RMSNorm) | ✅ | v5 | 어텐션 로짓 폭주 억제 → 학습 안정 | 없음(파라미터 없는 RMSNorm) | v4 NaN 발산의 주원인 해결. 메모리·FLOPs 중립 |
| **depth-delta** (층간 저랭크 델타) | 🚫 | v4 폐기 | (기각) rank_spectrum_v3 측정: excess/비용 효율 전 항목 1.0 미만 | — | "같은 메모리면 레이어 하나 더"에 항상 짐 |
| **mode routing / mode-delta** | 🧪 | v4~ (기본 off) | 토큰별 모드 라우팅 + 모드별 델타 | 라우터·델타 파라미터·연산 | `n_modes=1, mode_rank=0` 기본. adaLN만으로 충분 |
| **Ternary-LoRA 완화** (RRT식 층별 LoRA) | 🧪 | v6 (`--lora-rank`) | 공유 MLP 위에 층별 저랭크 보정 → 각 층 특화로 격차↓ | 메모리: fp16 r=16 → 1.46×, **ternary r=32 → 1.71×** | U=0 초기화로 시작 시 항등. 근거: RRT(ICLR 2025) |
| **FiLM 층별 조건화** | 🧪 | v6 (`--mlp-film`) | 공유 MLP 은닉을 층별 scale/shift로 변조 → 거의 공짜 차별화 | 파라미터 ~65K(≈0.13MB) → **감축 1.81× 유지** | LoRA보다 저렴한 rank-0 대안. shift/scale=0 초기화 |
| **깊고 얇게 + 공유** (`m100d`: 2+24+2, g6) | 🧪 | v6 (프리셋) | MLP 그룹 수는 유지(4), 깊이만↑ → 감축비 개선(~2.27× vs 자기 dense) | 절대 메모리 +2.5MB·연산 +40% | 근거: MobileLLM. 자체 dense와 별도 비교 필요 |
| **★연속 블록 공유(immediate sharing)** | ✅**외부 검증됨** | v4~ | 우리 `mid_mlps[j // g]` 는 **연속 g 층이 같은 MLP** 를 쓴다 = MobileLLM 의 *immediate block-wise weight sharing* 과 동일 형태 | 없음(이미 그렇게 돼 있다) | ★MobileLLM(arXiv:2402.14905)이 **모델 크기 증가 0·지연 오버헤드 미미**로 125M/350M 에서 **+0.7/0.8%p** 보고. **우리 설계 선택이 독립적으로 지지된다.** 그리고 이 배치가 **캐시 지역성 이득**(결과 014 §11: 층당 g8 0.913 ^< g4 1.022 ^< dense 1.163ms)과 **언팩 묶기**(P034 3C)를 가능하게 하는 전제다 |
| **★층별 LoRA 로 타잉 완화(RRT)** | 🧪**재부상** | v6 (`--lora-rank`, **기본 off**) | 공유 MLP 위에 층별 저랭크 보정. RRT 가 **layer-wise LoRA** 로 타잉 제약을 푸는 것과 동일 | 메모리 ternary r=32 → 1.71×(2.09× 대비 손해) | ★**현 후보 mA·mC 는 LoRA·FiLM 이 전부 꺼져 있다**(`mlp_lora_rank=0`). 구 측정은 **둘 다 도움**이었다(`t_lora32` 3.9220 / `t_film` 3.9420 vs `t_base` 3.9558). 근거: RRT(arXiv:2410.20672). **타잉 격차 +0.15~0.17 은 6배 토큰에도 안 닫혔고**(결과 006), 남은 유일한 품질 축이 이것이다 → **P008 재개 근거** |
| **prelude/coda 3+3 확장** | 💡 | — | 경계 독립층↑로 격차↓ | 감축 1.81→1.55× | 격차가 크면(+0.15↑) 후퇴 옵션 |
| **KDA 3:1 하이브리드 + NoPE** | 🔜 | — | 선형 어텐션으로 KV 대폭↓ | GPU 전용 chunkwise 커널(CPU 없음) | 컨텍스트 로드맵. 4번 참조 |
| ~~층별 LoRA·FiLM 완화~~ | 🚫**KD 조건에서 기각** | v6 | 공유 MLP 를 층마다 특화 | 메모리(LoRA 1.94×) / FiLM 0.13MB | 🚫**세 측정이 한 방향**: KD 없음 LoRA −0.0338·FiLM −0.0138 → KD 있음 둘 합쳐 −0.0065 → **KD+g8+paired FiLM 단독 +0.0003**(결과 027). **KD 가 그 자리를 차지했다.** 부수: 조건화 장치는 `grad_max` 를 키운다(FiLM 2.2배, LoRA 6.20) |
| **★LM 헤드가 추론 고정비의 주범**(신규) | 💡 | — (C-1·C-2) | 디코드 시간 = `a + b×층통과` 에서 **`a` = 3.3~4.3ms = 전체의 14~19%**. LM 헤드가 토큰당 **8.6M MAC**(층 하나 6.2M 보다 크다) + 32,768 vocab top-k | 로짓 랭크·샘플링 품질 | ~`a` −30~50% → 전체 −5~9%. **P046(E=128)이 절반을 노린다.** top-k partial sort 는 **값싼 즉효 후보**(C-2) |
| **깊고 얇게**(`m100d` 2+24+2, g6) | 🧪 프리셋 존재·미측정 | v6 | MLP 그룹 수 유지, 깊이만↑ | 절대 메모리 +2.5MB·연산 +40% | 📄MobileLLM 근거. **자체 dense 와 별도 비교 필요**(D-8) |
